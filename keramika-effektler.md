# Keramika effektləri: mamelonlar, incisal effektlər, xarakterizasiyalar

Bu bələdçi keramistlər üçündür: rəng və effektlərin **qlobal (beynəlxalq) adları** ilə.
Bu adlarla istənilən sistemdə (Noritake, Ivoclar, GC, VITA və s.) uyğun massanı tapmaq olar.
Hər bölmədə metal-keramika (məs. Noritake EX-3) və sirkon (məs. CZR / MiLai) üçün fərqlər ayrıca qeyd olunub.

> Brend kodları yalnız nümunə kimi verilib. İstehsalçılar çeşidi dəyişə bilər, ona görə
> konkret kodu həmişə öz kataloqunda / texniki təlimatında yoxla.

---

## 1. Əsas optik anlayışlar (qlobal terminlər)

| Termin | Mənası |
|---|---|
| **Hue** | Rəngin tonu (A, B, C, D qrupları: qırmızı-qəhvəyi, sarı, boz, qırmızı-boz) |
| **Chroma** | Rəngin doyğunluğu (intensivliyi) |
| **Value** | Parlaqlıq (açıq-tünd). Ən vacib parametr: value səhv olsa diş "boz" və ya "ölü" görünür |
| **Translucency** | İşıq keçirmə (şəffaflıq dərəcəsi) |
| **Opalescence** | Əks olunan işıqda mavi/boz/bənövşəyi parıltı (incisal hissədə) |
| **Counter-opalescence** | Keçən işıqda narıncı/kəhrəba parıltı (çox vaxt incisal kənarda) |
| **Fluorescence** | UV işıqda daxildən "işıqlanma" (təbii dentin güclü flüoresensiya edir) |
| **Luster / Gloss** | Səthin parıltısı |
| **Texture** | Səth relyefi: macro (lob, şırım) və micro (perikymata) |

## 2. Mamelonlar (Mamelons)

Mamelon — dentinin incisal hissədə "barmaq" kimi bitən inkişaf lobları. Adətən 3 lob olur,
gənc dişlərdə aydın, yaşlı dişlərdə (aşınma ilə) az görünür və ya heç görünmür.

### 2.1. Mamelon tipləri (forma)

| Tip | Qlobal ad | Görünüş |
|---|---|---|
| 1 | **Classic / three-lobe mamelons** | 3 aydın lob; halo mamelonların konturunu izləyir |
| 2 | **Split mamelons** | Böyük mamelon əlavə şaquli şırımla ikiyə bölünür |
| 3 | **Comb-like mamelons** | Çoxlu kiçik şaquli şırımlar, "daraq" kimi halo |
| — | **Worn / flat mamelons** | Yaşlı diş: mamelonlar yox olub, incisal kənar düzdür, daha çox chroma |

Pasiyentin qonşu dişlərinin fotosuna bax və hansı tip olduğunu təyin et — eyni tipi təkrarla.

### 2.2. Mamelon rəngləri (qlobal adlar)

| Qlobal ad | Rəng / effekt | Harada |
|---|---|---|
| **Mamelon Light / White** | Açıq, süd-ağ | Gənc, açıq rəngli dişlər, bleach rəngləri |
| **Mamelon Yellow** | Sarımtıl | Orta yaş, B rəngləri |
| **Mamelon Orange** | Narıncı | Ən çox istifadə olunan; A rəngləri, isti dişlər |
| **Mamelon Salmon** | Qızılbalıq (çəhrayı-narıncı) | Canlı, "isti" dentin effekti |
| **Mamelon Ochre / Dark Orange** | Tünd narıncı-qəhvəyi | Yaşlı dişlər, yüksək chroma |
| **Fluorescent / Fluo Mamelon** | Flüoresent mamelon | Təbii dentin kimi UV-də işıqlanma |

**Brendlərdə nümunələr:**
- Ivoclar IPS e.max Ceram: Mamelon (light və s.)
- VITA VM: Mamelon MM1–MM3
- Noritake: **Mamelon Orange 1 / 2** (CZR / EX-3), **Fluoro Mamelon 1 / 2** (Cerabien MiLai)

### 2.3. Addım-addım qatlama (cut-back texnikası)

1. **Baza**
   - *Metal-keramika:* Opaque → servikal hissədə **Opacious Dentin / Opaque Dentin** (Noritake: Opacious Body).
   - *Sirkon:* karkas üzərinə **internal stain / shade base** (sirkonun ağ "ölü" rəngini canlandırmaq üçün).
2. **Dentin (Body) tam anatomik forma** ilə qurulur (silikon açarla yoxla).
3. **Dentin cut-back:** incisal 1/3 və proksimal hissələr kəsilir, 3 mamelon "barmağı" formalaşdırılır.
   Mamelonlar arasında V-şəkilli boşluqlar qalır.
4. **Mamelon massası** mamelonların uclarına və ortasına nazik qatla qoyulur
   (əsasda daha çox chroma, uca doğru azalır).
5. **Mamelonlar arası (inter-mamelon):** **Opal Translucent / Blue / Grey** massa —
   mavi-boz "pəncərə" effekti üçün. Lazım olsa bir az **internal stain (blue / grey)**.
6. **Halo:** incisal kənar boyunca nazik xətt — **Incisal Edge / Halo** massa
   (ağ-opak və ya narıncı counter-opalescent). Daha təbii görünüş üçün palatinal tərəfə qoyulur.
7. **Proksimal translucency:** proksimal kənarlara **Translucent / Opal** massa;
   marginal tinlərə daha parlaq (yüksək value) enamel.
8. **Enamel (Incisal) qatı** — üstdən: **Enamel / Effect Enamel / Luster**. Bişmə kiçilməsini nəzərə alıb
   formanı bir az böyük qur.
9. **2-ci bişmə:** korreksiya, səth teksturası, glaze / polish.

**Alternativ — palatinal qabıq texnikası (palatal shell):** əvvəlcə silikon açarla palatinal enamel divarı
qurulur, sonra onun içinə dentin + mamelonlar + effektlər, sonda labial enamel. Bu, incisal effektlərin
yerini daha dəqiq idarə etməyə imkan verir.

### 2.4. Metal-keramika və sirkon fərqi (mamelonlar üçün)

| | Metal-keramika (EX-3 və s.) | Sirkon (CZR / MiLai və s.) |
|---|---|---|
| İşıq | Metal + opak işığı bloklayır → dərinlik az | Karkas işıq keçirir → daha təbii dərinlik |
| Yer | Keramika üçün yer məhduddur → mamelon effektlərini çox nazik et | Karkas anatomik kiçildilmiş (CAD cut-back) dizayn oluna bilər |
| Dərinlik hissi | Halo və translucent pəncərə daha vacibdir | Internal stain + nazik qatlarla dərinlik yaradılır |
| Yeni yanaşma | Opak üzərində internal stain | Mamelon strukturu CAD-də karkasın özünə dizayn edilir, üstündən micro-layering |

## 3. Incisal zona effektləri

| Qlobal ad | Nədir | Necə edilir |
|---|---|---|
| **Halo / Incisal Halo** | İncisal kənarda parlaq, ağımtıl və ya narıncı xətt | Nazik Halo / Incisal Edge / White opal xətti kənar boyunca |
| **Opalescence (blue/grey/violet)** | Mamelonlar arasında və incisal kənarda mavi-boz parıltı | **Opal Effect / Enamel Opal / Opal Translucent**, bəzən **Opal Booster** |
| **Counter-opalescence** | Keçən işıqda narıncı-kəhrəba halo | Narıncı/kəhrəba opal və ya halo massası kənarda |
| **Translucent window** | Mamelonlar arası və proksimal şəffaf zonalar | **Transpa / Translucent Clear, Neutral** |
| **Aqua / Blue enamel** | Soyuq, dərin incisal | Aqua / Blue enamel, T Blue |
| **Grey / Smoky zones** | Value-nu azaldan, "dərin" görünən zonalar | Grey translucent və ya **Light Absorber** |

**Brendlərdə nümunələr:**
- GC Initial MC: **Enamel Opal EOP-1…4**, **Enamel Opal Booster**
- VITA VM: **Effect Opal (EO)**, **Window (WIN)**
- Ivoclar e.max Ceram Selection: Special Enamel **Aqua, Quartz, Diamond**; Light Absorber **Fog, Lavender, Taupe**
- Noritake CZR / EX-3 (kataloqda yoxla): **Luster LT0, LT1, LT Natural, LT Super Gray, LT Yellow**,
  **T Blue**, **Aqua Blue 1 / 2**, **Incisal Aureola** (halo üçün), **Sun Bright**, **Creamy Enamel / Creamy White**,
  Translucent **T Clear, Tx, T0, T1, T2**

## 4. Xarakterizasiyalar (Characterizations)

| Qlobal ad | Görünüş | Necə edilir |
|---|---|---|
| **White spots / Hypocalcification** | Enamelin içində ağ ləkələr | Ağ effekt massa və ya **internal stain white** — dentin ilə enamel arasında |
| **Calcification flecks / Snowflakes** | Kiçik ağ "qar dənələri" | Çox az miqdarda ağ massa, fırçanın ucu ilə |
| **White bands / Banding** | Üfüqi ağımtıl zolaqlar | Nazik ağ/opal zolaq enamelin altında |
| **Craze lines / Enamel cracks** | Şaquli ağ nazik çatlar | **Internal stain white** nazik xətlə, şaquli istiqamətdə, uzunluq və intensivlik müxtəlif |
| **Stained cracks** | Qəhvəyi/kəhrəba çatlar (yaşlı diş) | Qəhvəyi / amber stain çox nazik xətlə |
| **Developmental grooves** | Loblar arası narıncı-qəhvəyi şırımlar | Narıncı/qəhvəyi internal stain loblar arasında |
| **Cervical chroma / Cervical warmth** | Servikal 1/3-də daha isti, doyğun rəng | **Cervical Translucent (CT)** — orange, amber, khaki |
| **High-value zones** | Marginal tinlər, loblar daha parlaq | **Light Reflector** (Cream, Salmon, Silk), parlaq enamel |
| **Low-value zones** | Daha "dərin", boz zonalar | **Light Absorber** (Fog, Lavender, Taupe), grey translucent |
| **Fluorescence** | UV-də canlı dentin | **Fluo Dentin / Fluoro** massa və ya stain; UV lampa ilə yoxla |
| **Surface texture** | Perikymata (üfüqi xətlər), loblar (şaquli), parıltı | Frezlə tekstura, nəzarətli glaze/polish |

**Brendlərdə nümunələr:**
- GC Initial MC: **Cervical Translucent CT-21…25**, **Fluo Dentin FD-91…93**, **INside IN-41…51**, **Enamel Occlusal EO-15…17**
- VITA VM: **Effect Enamel EE1–EE11**, **Effect Pearl EP1–EP3**, **Effect Liner EL1–EL6**
- Noritake (kataloqda yoxla): **Cervical CV-1…4**, **Cervical Enamel**; MiLai internal stain **White** (natural cracks),
  **Fluoro** (flüoresensiya), **Bright** (translucent effekt)

**Yaşa görə qayda:**
- *Gənc diş:* aydın mamelonlar, güclü opalescence, çox tekstura, az chroma.
- *Yaşlı diş:* aşınmış düz kənar, mamelon az və ya yox, daha çox chroma, çatlar, hamar səth.

## 5. Yeni texnikalar və materiallar

1. **Micro-layering (mikro qatlama)** — monolit / anatomik sirkon və ya litium disilikat (e.max) üzərində
   internal stain + 1–2 çox nazik keramika qatı. Daha az yer tələb edir, daha az qırılma riski, daha sürətli.
   - Noritake: **Cerabien MiLai** — aşağı temperaturlu keramika (740°C), sirkon və silikat keramika ilə uyğun.
     15 internal stain (o cümlədən **Bright**, **Fluoro**, **Incisal Blue 1 / 2**, **White**, toxuma rəngləri)
     və 16 porselan (o cümlədən **Fluoro Mamelon 1 / 2**).
2. **Internal Live Stain (ILS) / internal staining** — effektlərin qatlar arasına stain ilə çəkilməsi:
   opalescence üçün incisal blue, chroma üçün sarı-narıncı, çatlar üçün white. Dərin effektlər — stain ilə,
   səthə yaxın effektlər — massa ilə.
3. **Light Reflector / Light Absorber konsepsiyası** (Ivoclar e.max Ceram Selection) — rəngi dəyişmədən
   value-nu idarə etmək: parlaq zonalar üçün reflector, dərin zonalar üçün absorber.
4. **Opal Booster** (GC Initial) — çox güclü opal effekti; təmiz və ya enamel ilə qarışdırılır.
5. **3D effekt pastaları** (məs. GC Initial Lustre Pastes) — bişmiş səthə effekt əlavə etmək üçün.
6. **CAD anatomik cut-back** — mamelon strukturu karkasın özünə dizayn edilir, keramika qatı bərabər və nazik qalır.
7. **Cross-polarized foto** (polarizasiya filtri ilə) — parıltı olmadan dişin daxili strukturunu
   (mamelon, halo, opal zonaları) görmək və "xəritə" çəkmək üçün.

---

## 6. Praktik məsləhətlər

- Mamelon xarakterizasiyasını **az istifadə et** — həddən artıq kontrast süni görünür.
- İş zamanı restavrasiyanı **~50 sm məsafədən** yoxla: təbii effektlər yalnız yaxından görünməlidir.
- Əvvəlcə qonşu dişlərin fotosunda **effekt xəritəsi** çək (mamelon tipi, halo, opal zonaları, white spots).
- Dərin effektləri stain ilə, səth effektlərini massa ilə et.
- Hər yeni massanı əvvəlcə **test nümunəsində** (rəng tableti) bişir — eyni ad müxtəlif brendlərdə fərqli görünə bilər.
- Flüoresensiyanı UV lampa altında yoxla — restavrasiya qonşu dişlərdən "qaranlıq" görünməməlidir.
